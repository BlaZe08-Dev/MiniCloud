## Open questions

1. **Note 17.** The task says Go passes durations, never wall-clock times. ADR Section 4.4 says the pass receives the grace state exactly as `SweepExpiredLeases` does, and that state holds instants. I followed the ADR. The instants come from `repo.Now`, which is the database clock, never the process clock. Accept?
2. **Note 22.** Keep the config copy of the A1 rules with the cross-test, or remove it? Removing it means config imports coordinator, and its errors no longer name the variables, which A1 asks for.
3. **Note 16.** No lapse is counted before the sweeper's first successful tick or after a failed tick. Accept?
4. **F-5c-1** (minor, inferred, not measured). Each submit adds at most one pass, but rounds started by back-to-back submits have no yield between them. The unauthenticated submit endpoint (SEC-004) can therefore keep passes running. Should the trigger be throttled? The part 2 abuse suite (FS-24) could measure this.

   - The ADR-0017 status note is stale (slice 5c "not started"). It is older text.
