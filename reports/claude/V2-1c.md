## 7. Beyond the ADR
1. Paging: `limit` default 100, max 500, `after` canonical UUID, `next_cursor` = last node_id when the page is full (so an exactly-full last page returns a cursor and the next page is empty), placeholders, not measured. Envelope key `nodes`.
2. Node ceiling: `MINICLOUD_NODE_MAX_COUNT` default 10000 (placeholder), 429 `NODE_LIMIT_REACHED`, no Retry-After, existing nodes unaffected (coordinator/nodes.go:37). It is soft: concurrent registrations of new IDs can overshoot by at most the number of concurrent requests (documented in protocol.md 7.1 and field-limits.md section 4).
3. `telemetry_age_ms` = coordinator clock minus stored `received_at`, display only, clamped at 0 (api/nodes.go:81).
4. A-01 raw JSON: `registerWorkerRequest` embeds `domain.Worker` and shadows `node_id` with `json.RawMessage` (handlers.go:322 region). Not served: ignored whatever its type. Note: the task says the not-served behaviour is "exactly as on origin/main (200 for node_id 5)". On origin/main 411ea09 `node_id: 5` actually gave 400 MALFORMED_JSON (audit A-01); I implemented the V1 behaviour the task states (200), which is what the V1 release did.
5. `sample_age_ms` rule (corrected in fix round 1, audit F-01): "sampled_at not before created_at" is enforced by storage on the repository clock (database clock in PostgreSQL, injected clock in memory), inside `RecordNodeTelemetry`, with the same time value that is stored (postgres/nodes.go:168-178, inmemory_nodes.go:155-159). The coordinator no longer reads the node (coordinator/nodes.go:76-89). Outcome order: unknown node 404, then this rule 400, then session and sequence 409. The first version of this report said the coordinator enforced it through GetNode; that was wrong and is superseded.
6. Validation order: node ID, then contract version (so an unsupported version is `UNSUPPORTED_CONTRACT_VERSION` even with other bad fields), then the rest.
7. A value of the wrong JSON type is 400 `MALFORMED_JSON` (decode error), not `INVALID_REQUEST`; documented.
8. Logs: coordinator logs only node ID (validated UUID) and a failure class for ceiling and rate limit; no node string. The local-only line carries the boolean only.
9. PostgreSQL `ListNodes` rejects a NUL in the cursor with ErrInvalidRequest.
10. `ErrNodeNotFound` is mapped to 404 NODE_NOT_FOUND in the shared table; worker register turns it into 400 INVALID_REQUEST before the table.

## 8. Gaps
