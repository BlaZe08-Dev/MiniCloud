# MiniCloud P4-07 Final Report: CLI Terminal Output Sanitization (SEC-048)

## 1. Summary of Changes by File

- `cmd/mc/sanitize.go`:
  - Implemented `func sanitize(s string) string` to sanitize arbitrary text before terminal display.
  - Normalizes `\r\n` (CRLF) to standard `\n` (LF) to preserve legitimate multi-line formatting.
  - Replaces lone `\r` with literal visible `\r` (`\x5c\x72`) to prevent line-clearing terminal overwrites.
  - Preserves standard printable characters, horizontal tab (`\t`), and newline (`\n`).
  - Replaces all ASCII control codes (C0, DEL) and C1 control characters (`U+0080`..`U+009F`) with visible escape representations (`\x..` or `\u....`), neutralizing ANSI escape sequences, cursor manipulation, screen clearing, OSC hyperlinks, and title rewriting.
  - Replaces invalid UTF-8 bytes (`r == utf8.RuneError && size == 1`) with hex escape `\x..` (e.g. `\xff`).
  - Replaces unprintable Unicode formatting runes (bidi overrides `U+202E`/`U+202D`, zero-width space `U+200B`, BOM `U+FEFF`, line/paragraph separators `U+2028`/`U+2029`, and NBSP `U+00A0`) with `\u....` or `\U........`.
  - Policy for NBSP (`U+00A0`): Escaped as `\u00a0`. NBSP renders visually identical to ASCII space (`0x20`), enabling terminal visual spoofing of task names, worker IDs, or CLI arguments. Escaping makes non-ASCII whitespace explicitly visible to operators.
  - Implemented `func sanitizeJSON(s string) string`:
    - Rewrites only C1 control characters (`U+0080..U+009F`) and DEL (`0x7f`) to JSON-valid `\u00xx` escapes while leaving all other bytes untouched.
    - Preserves valid JSON syntax and guarantees decode-equality with the original payload when decoded with `json.Unmarshal`.

- `cmd/mc/sanitize_test.go`:
  - Table-driven unit tests (`TestSanitize`) verifying ESC clear-screen (`\x1b[2J`), OSC title change (`\x1b]0;pwned-title\x07`), backspace (`foo\x08\x08bar`), lone CR (`hello\rworld`), CRLF normalization (`line1\r\nline2\r\n`), multiple CRs before LF (`\r\r\n`), C1 controls (`\u0080\u009b`), DEL (`abc\x7fdef`), NUL byte (`\x00`), C0 controls (`\x00\x01`), bidi overrides `U+202E` and `U+202D`, zero-width space `U+200B`, BOM `U+FEFF`, line/paragraph separators `U+2028` and `U+2029`, NBSP `U+00A0`, invalid UTF-8 bytes (`\xff\xfe\x80`), valid UTF-8 text, tab/newline preservation, and empty strings.
  - Stress test `TestSanitize_64KiBMixedHostileText` testing exactly 65,536 bytes (64 KiB) of mixed hostile text containing C0/C1 codes, lone CR, DEL, bidi overrides, NBSP, NUL, and invalid bytes, asserting the exact expected string.
  - `TestSanitizeJSON` asserting standard JSON passes untouched, hostile C1/DEL bytes are rewritten to `\u00xx` escapes, `json.Valid` returns true, and `json.Unmarshal` decode-equality holds against the original JSON.
