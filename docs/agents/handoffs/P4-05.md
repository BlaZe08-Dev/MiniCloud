### F-03 Observation & Open Design Question for Orchestrator
- **Observation**: In coordinator work dispatch (`internal/coordinator/service.go:RequestWork`), a configured lease duration shorter than one second produces `lease_duration_seconds: 0` via integer truncation (`int(s.leaseDuration / time.Second)`), causing the worker's `renewalInterval` (`internal/worker/client.go:renewalInterval`) to evaluate `a.LeaseDurationSeconds <= 0` and fall back to the 10-second default (`DefaultRenewalInterval`).
- **Open Design Question**: No minimum lease value is enforced in configuration (`MINICLOUD_LEASE_DURATION`). If a coordinator operator configures a sub-second lease (or any lease shorter than the worker's 10-second default renewal interval), the attempt would lapse and be reaped by the sweeper before the worker ever attempts its first renewal. Should configuration validation enforce a minimum lease value (e.g., `MINICLOUD_LEASE_DURATION >= 1s` or `>= 3s`)?
