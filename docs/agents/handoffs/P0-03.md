Design decisions and deviations from the design doc (with reasons):
- **Selective Subshell Export**: In PostgreSQL mode, commands use `( export MINICLOUD_DATABASE_URL="$(grep -E '^MINICLOUD_DATABASE_URL=' .env | cut -d= -f2-)"; ... )` inside subshells. This ensures that `MINICLOUD_TEST_DATABASE_URL` is never exported, passwords containing `&` or special characters are safely preserved, and no environment variables leak into the parent interactive shell.
- **In-Memory Quick Start Order and Readiness**: The quick start explicitly specifies startup order, adds readiness polling against `/readyz`, and clarifies that `mc` commands should be issued after the worker registers.
- **Port Isolation**: Quickstart verification was performed on free port 18080 to prevent collisions with any existing daemon on port 8080.
- **Strict Formatting Constraints**: No badges, no screenshots, no marketing claims, no emojis, no line-number citations.

Additionally, passwords with special characters such as `&` break shell assignment. Resolved by replacing with selective subshell extraction `( export MINICLOUD_DATABASE_URL=...; ... )`.

    - *Result* [confirmed by code reading]: `docs/security/findings.md` tracks SEC-012 for the worker execution timeout clamp, but `docs/phase4-plan.md` does not schedule it. Removed the schedule claim from documentation.

    - *Result* [confirmed by code reading]: Only `mc submit` supports `--coordinator-url`; `mc get`, `mc attempts`, and `mc workers` read `MINICLOUD_COORDINATOR_URL` from the environment. Documented setting the environment variable in the user shell.
