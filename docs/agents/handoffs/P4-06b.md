- `docs/protocol.md` and `docs/failure-model.md`:
  - **Server Timeouts & Deadlines**: Documented `RequestTimeout` 8s context deadline enforced across all HTTP API requests (`requestDeadlineMiddleware` in `internal/api/handlers.go`). Requests blocking for >8s abort and return HTTP 503 `SERVICE_UNAVAILABLE` with `Retry-After: 1`. Documented accepted limit (F-4e-3 / `SEC-033`): pgx connection pool recovery after a healed half-open partition takes up to ~15s due to internal `asyncClose`. Documented `BackgroundCallTimeout` 8s per iteration on sweeper ticks and worker reaper iterations (`internal/coordinator/service.go`).
  - **Defensive Text Clamping (`ClampText`)**: Documented `ClampText` semantics (`internal/executor/truncate.go`): NUL (`\x00`) bytes and invalid UTF-8 sequences replaced with `\uFFFD` (3 bytes in UTF-8). String length measured after byte replacement; cut backward to the nearest valid UTF-8 rune boundary and suffixed with `\n[truncated]` to strictly bound output to 64 KiB and attempt error text to 10 KiB.
  - **Worker Fallback Failure Report**: Documented that on HTTP 400 validation rejection (`INVALID_REQUEST` or `OUTPUT_TOO_LARGE`), the worker sends exactly one fallback failure report (exit 1, empty output, `PERMANENT`, error summary citing the 400 rejection) with ongoing renewals to move the job to `FAILED` on attempt 1 and avoid burning attempt budgets. Documented deliberate exclusion of `MALFORMED_JSON` to permit clean at-least-once retry upon transport corruption.
  - **Ambiguous Commit Replay**: Documented HTTP 409 `JOB_ALREADY_TERMINAL` response on retry of an already-committed result, confirming single result row integrity and idempotent behavior (`SEC-031`, Informational).
  - **Heartbeat Available Slots**: Documented that `available_slots` integer in heartbeat payloads is accepted for protocol compatibility but ignored; capacity is dynamically derived from active attempts (`SEC-055`, Informational).
  - **Work-Poll Database Cost**: Documented database flight costs: ~20 round trips for job claim, 4 for empty poll, 5 for submit; networks with latency >400ms per round trip approach the 8s request deadline (`SEC-037`, Informational).
