## Design decisions and deviations (with reasons)

- SEC-048 sanitization covers `mc` output of worker-supplied text (`cmd/mc/sanitize.go`), not AI CLI output. The prompt labels "noisy tool output" as [Decided: SEC-048]. I split the label: [Decided] for the `mc` sanitization and the 64 KiB output cap (`AGENTS.md` invariant 4), [Proposed] for applying it to AI CLI output. No contradiction needing a stop; a precision correction.
- "Exponential backoff with jitter in the worker" exists as the poll-loop backoff (`internal/worker/client.go:74`). Job-retry backoff is coordinator-side (`internal/domain/retry.go`, ADR-0015). Both are cited under their real owner.
- "Claim SQL filters by supported_tasks": three places, cited with lines: `internal/storage/postgres/assignment.go:387`, `:476`, `:578`, and `repository.go:848`.
- "Linux amd64: V1 tested": the only evidence is that the development host is linux/amd64 (`go env`) and the repo has no CI config. Fix 1: it is now an observation, not [Decided]; no test-matrix claim.
- README and docs scan: no sentence claims more than Linux support (searched Windows, macOS, cross-platform, portable, device, machine). Forward-looking V3 multi-machine lines in README and `docs/architecture.md` are plans. No correction was needed; `README.md` not edited.
