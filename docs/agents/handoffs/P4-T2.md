## Design (confirmed by code reading and executed)
1. `const frozenReviewDir = "docs/agents/reviews/"` with a comment saying why, in `tests/docs/citations_test.go`.
2. `IsFrozenReviewRecord(fsys, rel)`: true only if `rel` is already clean (`path.Clean(rel)==rel`, so `../`, `./`, `//` forms fail), starts with the exact prefix including the trailing slash (`reviews-old/`, `reviews.md`, `Reviews/` fail), and no path component is a symlink (checked via `fs.ReadDir` entry types, because Go 1.22 has no `fs.Lstat`).
3. `CheckRuleA` skips only its markdown-link-target loop for frozen files. Every other rule, and every file outside the directory, runs unchanged. The allowlist is unchanged.
4. Why skip instead of re-resolve: re-resolving cannot pass the `0014-...md` placeholder (above). Syntactic code-span existence checks remain, so a record citing a path that never existed in code spans still fails.
5. Seam: the checkers already take an `fs.FS`, so no new seam was needed; tests use `fstest.MapFS`, and a real temp dir for symlinks.
