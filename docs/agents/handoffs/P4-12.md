Design decisions and deviations from the design doc (with reasons):
- Guard implementation uses pure POSIX parameter expansion (`NO_QUERY="${RAW_URL%%\?*}"` and path stripping) to reliably extract database names from full URLs without external binary dependencies.
- Exit code 2 is returned when refusing execution early, preserving standard Unix convention for command-line syntax/usage errors while differentiating from make's own exit code 1 or test failures.
- Zero Go files modified; citation allowlist untouched; no line numbers in live docs.
