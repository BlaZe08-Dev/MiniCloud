## Overview

Task P4-T1 adds test-safety guards to prevent accidental disruption of the shared PostgreSQL container and unintended test database access. The implementation introduces:
- A pure dual-variable opt-in guard (`containerControlAllowed`) requiring both `MINICLOUD_ALLOW_CONTAINER_RESTART=1` and `MINICLOUD_CONFIRM_CONTAINER=minicloud-postgres`.
- Skip guards (`requireContainerControl`) at the entry of the three container-restarting outage tests, plus defence-in-depth failure guards (`refuseWithoutContainerControl`) inside the Docker execution helpers `stopPostgresContainer` and `startPostgresContainer`.
- An AST-based static scan (`TestEveryContainerRestartingTestCallsTheGuard`) enforcing that every test in `tests/integration` that invokes the Docker helpers calls `requireContainerControl(t)` as its first statement.
- Database name validation (`isTestDatabaseName`) ensuring tests refuse any database not ending in `_test` prior to connection or execution, fixing SEC-023 in `TestMigrator_PreExistingInvalidRow_ValidationFails`.
- An AST-based static scan (`TestEveryTestURLConsumerHasNameGuard`) verifying all `MINICLOUD_TEST_DATABASE_URL` consumers in `internal/storage/postgres` carry name guards.
- Makefile false-green count guards for `test-db` and `test-outage` verifying `-run` patterns match the exact expected number of tests before test execution begins.
