89:Port-busy advice: If port 8080 is busy (`ss -tulpn | grep 8080` or `ss -ltn | grep 8080`), the coordinator logs `address already in use` and exits. The worker and `mc` default to port 8080 and will silently talk to whatever foreign process is listening there. To use a different port (such as 18080), set `MINICLOUD_HTTP_ADDR=127.0.0.1:18080` when starting the coordinator, and set `MINICLOUD_COORDINATOR_URL=http://127.0.0.1:18080` for the worker and in your `mc` shell (`export MINICLOUD_COORDINATOR_URL=http://127.0.0.1:18080`). Note that while `mc submit` supports a `--coordinator-url` flag, other `mc` subcommands (`mc get`, `mc attempts`, `mc workers`) read `MINICLOUD_COORDINATOR_URL` from the environment.
