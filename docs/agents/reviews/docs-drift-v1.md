The following documents do not currently exist in the repository but should be created before V1 completion to document new operational and protocol interfaces:

   - **Purpose**: Operational tuning guide detailing `MINICLOUD_DISPATCH_POLICY` and the 6 assignment configuration variables (`MINICLOUD_ASSIGNMENT_ACCEPT_WINDOW`, `MINICLOUD_ASSIGNMENT_INTERVAL`, `MINICLOUD_ASSIGNMENT_MAX_LAPSES`, `MINICLOUD_ASSIGNMENT_FALLBACK_AGE`, `MINICLOUD_ASSIGNMENT_BATCH_LIMIT`, `MINICLOUD_ASSIGNMENT_MIN_YIELD`). Explains strict parser error behavior, fallback triggers to FIFO pull, batch sizing considerations, and cluster capacity implications.
   - **Suggested Owner**: Gemini (or Claude Code during coordinator assignment loop integration).

2. **API Reference for New Assignment Fields** (proposed new doc: docs/protocol/assignment-api.md or protocol addendum)
   - **Purpose**: Normative API reference documenting additive wire fields for `POST /v1/workers/{worker_id}/poll` (`policy`, `fallback_reason`) and `GET /v1/jobs/{id}` (`assigned_worker_id`, `assignment_expires_at`, `assignment_lapses`, `assignment_fallback_reason`), specifying field types, allowed enumeration values, nullability semantics, and JSON envelopes per ADR-0017 Section 5.1.
   - **Suggested Owner**: Claude Code (as part of slice P4-08e wire implementation).
