func ComputeBackoffWithJitter(failureCount int, base, max time.Duration) time.Duration {
	if failureCount <= 0 {
		return base
	}
	multiplier := 1 << (failureCount - 1)
	if multiplier > 16 {
		multiplier = 16
	}
	dur := base * time.Duration(multiplier)
	if dur > max {
		dur = max
	}
	jitterFrac := 0.5 + rand.Float64()*0.5
	return time.Duration(float64(dur) * jitterFrac)
}

187:- **Worker-Side Result Delivery Pairing During Outages**:
188-  Coordinator-side grace periods must be paired with worker-side delivery resilience. If a task completes execution during a coordinator or database outage, the worker's result delivery loop (`internal/worker/client.go` function `deliverResult`) retries `ReportResult` with capped jittered backoff (200ms base to 5.0s cap) and concurrently continues issuing lease renewals until the coordinator recovers, operating under a 60-second time-bounded delivery budget (`deliverResult` called from `ExecuteAndReport`).
